# Micrographics Selection Guide

Use this file when the user wants a quick starting point without rereading the full catalogs.

## Preferred Sets

- Default to `Editable Text` for text-bearing graphics we may adapt later.
- Default to `Components Library` for dividers, frames, badges, diagrams, and ambient geometry.
- Ignore `Non-Editable Text` unless exact outline text is required.

## MVP Editable Shortlist

- `Editable 16 - EpochTransformVerificationPanel`: strongest hero or manifesto panel.
- `Editable 31 - TimeEngineSyncBanner`: reliable section header.
- `Editable 34 - GatewayTargetCoordinatesPanel`: large featured project card.
- `Editable 47 - RestartBandwidthProgressDial`: radial accent for hero, stats, or CTA.
- `Editable 58 - DigitalOutputChannelPanel`: sidebar, timeline, or vertical rail.

## MVP Base Library Shortlist

- `Component 14 - ConcentricArcRadarScale`: hero radar motif.
- `Component 29 - RadialNodeNetwork`: project architecture or systems diagram.
- `Component 80 - BidirectionalArrowDivider`: strong section separator.
- `Component 116 - ArrowHeaderCard`: card shell or highlighted content block.
- `Component 131 - OrbitArcDivider`: softer section separator.
- `Component 150 - GlobeGridBadge`: metadata or footer badge.

## Good Starting Combinations

- Hero: `Editable 16` + `Component 14` or `Component 130`
- Section header: `Editable 31` + `Component 131` or `Component 80`
- Featured project card: `Editable 34` + `Component 116` or `Component 54`
- Sidebar or timeline: `Editable 58` + `Component 65` or `Component 122`
- CTA or footer accent: `Editable 47` + `Component 108` or `Component 150`

## Cautions

- Avoid stacking multiple text-heavy editable assets in the same viewport.
- Use the more dramatic error/offline panels sparingly.
- Prefer one dominant radial motif per section; several together make the UI feel crowded fast.
