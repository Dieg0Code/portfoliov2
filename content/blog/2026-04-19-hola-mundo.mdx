Este es el primer post. Sirve doble: inauguro el blog y confirmo que el
pipeline MDX está renderizando todo lo que necesito.

## Por qué un blog propio

Porque escribir en Medium o dev.to es prestado, y porque quiero meter
componentes React custom inline. No encontré nada más directo que `.mdx`
en una carpeta + Next.js leyendo el filesystem en build.

<Callout tone="info" title="Stack">
  `next-mdx-remote/rsc` + `gray-matter` + `remark-gfm` + `rehype-pretty-code`
  sobre `shiki`. Mermaid se carga lazy solo si el post lo necesita.
</Callout>

## Code blocks

Un bloque de Python:

```python
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print(fib(10))  # 55
```
